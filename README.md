# Activities Tracker (Neon)

Aplikasi web untuk memantau activity, task, vendor, issue, risiko, dan dokumen SR/PR/PO.

- Data tersimpan di database Neon (Postgres) dan diakses lewat Neon Data API.
- Login memakai Neon Auth; akses diatur dengan Row Level Security (editor / viewer).
- Tidak ada password atau kunci rahasia di repository ini.
